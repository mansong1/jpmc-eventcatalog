## Overview

A merge to `main` arrives on [[channel|delivery.github-webhooks]] and starts [[service|rc-build]]. [[service|release-orchestration]] and the [[service|delivery-cli]] start deploys through the [[channel|delivery.harness-pipeline-api]]. The [[service|promotion-gate]] decides each promotion. A failed gate reaches the [[service|rc-autofix-agents]] over the [[channel|delivery.chained-stage]]. The [[service|ecs-runtime]] on AWS sits outside the system.
