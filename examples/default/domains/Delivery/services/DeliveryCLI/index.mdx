## Overview

Everything is driven from the command line. `bin/ec` is a Python renderer that prints generated pipeline YAML to stdout and makes no API calls. The `harness` CLI runs that YAML as a dynamic execution of the saved shell pipeline `ec_dynamic` (`bin/ec preview 42 | harness execute pipeline:dynamic ec_dynamic -f -`), and the executed YAML is stored on the run.

The same CLI starts saved pipelines (`release_candidate`, `deploy_ecs*`), approves or rejects approval steps, and retries stages. Dynamic runs take no input sets or runtime inputs, so `ec` bakes the values into the YAML, where they can be reviewed. On-run OPA policies evaluate that YAML like any saved pipeline.
