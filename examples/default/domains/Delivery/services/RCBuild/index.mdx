## Overview

The first stage of `release_candidate` (also generated as the standalone `rc_build` pipeline for Release Orchestration).

| Gate | Scanner | Fails on |
|---|---|---|
| secrets | Gitleaks (repository) | medium (reviewed allowlist in `.gitleaks.toml`) |
| SAST | Semgrep (repository) | critical |
| SCA | OsvScanner (repository) | report-only |
| image | AquaTrivy on the locally built image, before push | critical |

Only after all gates pass is the image pushed as `rc-<sha>`. Every later deployment reads that one tag, and nothing is rebuilt.
