## Overview

Process `eventcatalog_release` runs three phases: `jpmc_rc` → `jpmc_staging` → `jpmc_prod`. Its activities run `rc_build` and the deploy pipelines. Outputs are chained across phases, `IMAGE_TAG` → dev `DEPLOYED_TAG` → staging → manual *Approve prod release* → prod, using `<+phase.<phase>.activity.<activity>.outputs.<name>>` references.

Activities and the process are created and updated over the API. Starting a release has no API and is a click in the UI.
