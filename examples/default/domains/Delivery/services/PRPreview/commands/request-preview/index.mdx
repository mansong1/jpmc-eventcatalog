## Overview

Sent by the GitHub PR trigger `pr_preview_github`, or by [[service|delivery-cli]] for a re-run. It's a saved pipeline, so a failed stage can be retried (`harness execute execution:retry pr_preview/<exec> --retry-stages deploy`).
