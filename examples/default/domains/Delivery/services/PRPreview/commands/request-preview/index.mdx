## Overview

Sent by the GitHub PR trigger `pr_preview_github` (→ `pr_preview`), or by [[service|delivery-cli]] as `harness execute pipeline laptop_preview --input pr=<n> --input who=<you>`. Both are saved pipelines, so a failed stage can be retried (`harness execute execution:retry pr_preview/<exec> --retry-stages deploy`). Don't start `laptop_preview` while `pr_preview` has the same PR's preview open: they share its slot and ECS service.
