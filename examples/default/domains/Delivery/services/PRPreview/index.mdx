## Overview

Started by a GitHub PR (trigger `pr_preview_github` → saved pipeline `pr_preview`) or by [[command|request-preview]] from the CLI.

1. **Functional build.** Runs on Harness Cloud, or on the developer's own Mac through Delegate 3.0 (`jpmc-mac-<who>`). On the laptop path the Mac uploads `dist/` to a single short-lived signed URL. Cloud then re-verifies the SHA-256 and page count and packages a static nginx image, so no credential sits on the laptop.
2. **Slot.** IaCM (OpenTofu) workspace `jpmc_pv_pr_<n>` gives the PR its own ALB listener port and target group.
3. **Deploy.** ECS service `jpmc-eventcatalog-pr-<n>`, then [[event|preview-deployed]] with the URL.
4. **Review.** A 24h approval. Accept keeps the preview until `expires_at`. Reject or timeout tears down the service, then the slot.

The hourly `cleanup_generated` janitor removes expired pipelines, preview workspaces and orphan ECS services.
